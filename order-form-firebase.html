پنل مدیریت سفارش‌ها

راه‌اندازی دیتابیس (یک‌بار)

  1. یک حساب رایگان در console.firebase.google.com بسازید (با همون حساب گوگل خودتون).
  2. روی Add project بزنید، یه اسم بذارید و پروژه رو بسازید (نیازی به کارت بانکی نیست).
  3. از منوی سمت چپ، Build → Firestore Database رو باز کنید، روی Create database بزنید و حالت Start in test mode رو انتخاب کنید (بعداً قوانینش رو با کد زیر عوض می‌کنیم).
  4. از منوی سمت چپ، Build → Authentication رو باز کنید، روی Get started بزنید، و provider Email/Password رو فعال کنید.
  5. برید به تب Rules داخل Firestore Database، کد زیر رو کپی و جایگزین محتوای فعلی کنید، بعد Publish بزنید:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /orders/{orderId} {
      allow read: if true;
      allow create: if true;
      allow update: if true;
      allow delete: if true;
    }
  }
}
  1. برگردید به صفحه اصلی پروژه (آیکون ⚙ کنار «Project Overview» → Project settings)، پایین صفحه دنبال بخش Your apps بگردید، روی آیکون وب (</>) بزنید و یه اپ وب ثبت کنید.
  2. یه شیء (object) به اسم firebaseConfig بهتون نشون داده می‌شه. کل مقادیرش رو کپی کنید.
  3. داخل همین فایل، در ابتدای تگ <script> پایینی، مقدار firebaseConfig رو با همونی که کپی کردید جایگزین کنید و فایل رو دوباره در گیت‌هاب آپلود کنید.
