راه‌اندازی دیتابیس (یک‌بار)

  1. یک حساب رایگان در supabase.com بسازید و یک پروژه جدید بسازید.
  2. وارد بخش SQL Editor پروژه بشید، کد زیر رو کپی و اجرا کنید (فقط یک‌بار لازمه):
-- این کد رو در Supabase > SQL Editor اجرا کنید

create table orders (
  id bigint generated always as identity primary key,
  full_name text not null,
  postal text not null,
  address text not null,
  rubika_id text not null,
  order_code text not null,
  normalized_name text not null unique,
  created_at timestamptz not null default now()
);

alter table orders enable row level security;

create policy "anyone can insert orders"
on orders for insert to anon with check (true);

create policy "anyone can read orders"
on orders for select to anon using (true);

create policy "anyone can update orders"
on orders for update to anon using (true);

create policy "anyone can delete orders"
on orders for delete to anon using (true);
  1. برید به Project Settings → API و دو مقدار Project URL و anon public key رو بردارید.
  2. داخل همین فایل، در ابتدای تگ <script> پایینی، مقادیر SUPABASE_URL و SUPABASE_ANON_KEY رو با همون‌ها جایگزین کنید و فایل رو دوباره در گیت‌هاب آپلود کنید.
